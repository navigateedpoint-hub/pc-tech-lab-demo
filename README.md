# PC Tech Lab – Guided Demo (all categories)

Open `index.html` in this folder and choose a category. Everything works offline from the unzipped folder.

| Folder | Category | Stations |
|---|---|---|
| `1-Install-and-Configure-Computer-Systems` | Install and Configure Computer Systems | 1 PC Assembly · 2 OS Installation |
| `2-Set-up-Computer-Networks` | Set-up Computer Networks | 3 Cable Termination · 4 Network Setup |
| `3-Set-up-Computer-Servers` | Set-up Computer Servers | 5 Server Setup |

Each category folder is self-contained (it has its own `shared` folder) and has its own colour theme. The steps, drawings and controls are the same as before. Station 2 still leads on to Station 3, and Station 4 to the Server Setup category.

Keys in every station: → next · ← back · S hands-on/slides · F full screen.
